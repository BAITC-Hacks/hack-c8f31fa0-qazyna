# AGENTS.md — инструкции для Codex

## Проект
ИИ-консультант для чата на сайте ekt.kz (HackAlem AI, трек «Торговля», партнёр ТОО «Электрокомплект»).
Консультирует по каталогу электротехники: наличие, характеристики, сертификаты, аналоги, условия покупки.
Добавляет товар в корзину ТОЛЬКО после явного подтверждения клиента.

## Стек
Python 3.11+, OpenAI SDK (function calling), Streamlit, requests. Секреты — в `.env` (не коммитить!).

## Структура
- `agent/catalog.py` — загрузка каталога (API ekt.kz или `data/catalog_sample.json`), поиск, аналоги.
  `normalize_api_product()` приводит ответ API к единому формату товара.
- `agent/cart.py` — корзина. Защита: propose → явное подтверждение отдельным сообщением → confirm.
  Проверка подтверждения и остатков — в коде, не в промпте.
- `agent/tools.py` — инструменты агента + `TOOL_SCHEMAS`.
- `agent/agent.py` — системный промпт и агентный цикл.
- `app.py` — Streamlit-демо (чат, корзина, страница корзины `/?cart=<id>`).
- `data/purchase_terms.json` — условия оплаты/доставки/мин. партии (ДЕМО, заменить на реальные).
- `tests/test_must_have.py` — тесты по пунктам Must have кейса.

## Команды
- `pip install -r requirements.txt`
- `pytest -q` — должны проходить всегда
- `streamlit run app.py`
- `python -m agent.agent` — консольный режим

## Жёсткие правила (из ТЗ партнёра — не нарушать)
- Корзина меняется только через `Cart.confirm()` после явного подтверждения. Не добавлять обходных путей.
- Количество в корзине никогда не превышает остаток; учитывать минимальную партию.
- Цены/наличие/характеристики — только из каталога. Модель не должна их придумывать.
- Не запрашивать и не хранить платёжные данные клиента.
- Аналоги всегда с обоснованием (совпадающие характеристики, отличия, разница в цене).
- Логин/пароль API ekt.kz только в `.env`, никогда в коде и коммитах.

## Стиль работы
- Новый инструмент = метод в `Toolbox` + схема в `TOOL_SCHEMAS` + тест.
- После изменений запускай `pytest -q`.
- Маленькие изменения; тексты для клиента — на русском (и казахском, если клиент пишет по-казахски).
