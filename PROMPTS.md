# Промпты для Codex — по порядку

После каждого шага: проверить в PyCharm → `pytest -q` → GitHub Desktop: Pull → Commit → Push.

## 0. Знакомство (первым делом)
> Прочитай AGENTS.md и весь проект. Создай .venv, установи requirements.txt, запусти pytest. Коротко объясни, как устроен проект.

## 1. Подключить живой API ekt.kz (самое важное)
> В .env есть EKT_API_USER и EKT_API_PASSWORD (basic auth). Сделай запрос к https://ekt.kz/api/products и https://ekt.kz/api/products/detail?id=515291, сохрани пример ответа в data/api_sample_list.json и data/api_sample_detail.json. Посмотри реальные имена полей и перепиши normalize_api_product() и load_from_api() в agent/catalog.py под них (пагинация через ?page=N). Если детали (характеристики, сертификаты, остатки) есть только в detail — подгружай detail для найденных товаров. Добавь тест. Не коммить пароли.

## 2. Кэш каталога
> Сделай скрипт scripts/fetch_catalog.py, который выкачивает N страниц каталога из API и сохраняет в data/catalog_cache.json в нашем формате. Catalog должен читать кэш, если он есть — чтобы демо работало быстро и без интернета.

## 3. Лучший поиск
> Улучши Catalog.search(): учитывай опечатки и синонимы («автомат» = «автоматический выключатель», «узо» = «устройство защитного отключения», «А» = ампер). Добавь тесты на 5 типичных запросов клиента.

## 4. Вложения (Excel / PDF / фото спецификации)
> Добавь в app.py загрузку файла (xlsx, docx, pdf, jpg). Из Excel/Word/PDF вытащи текст и найди артикулы/наименования, из фото — распознай через модель с vision. Передай найденные позиции агенту как контекст: «клиент приложил спецификацию: ...». Агент должен проверить наличие каждой позиции и предложить аналоги для отсутствующих.

## 5. Опционально (плюсы для жюри)
> Добавь: рекомендации сопутствующих товаров (к автомату — DIN-рейка, бокс; к кабелю — гофра), эскалацию на менеджера (кнопка «Позвать менеджера» + сводка диалога), ответы на казахском.

## 6. Виджет для сайта
> Сделай простой HTML/JS виджет чата (static/widget.html), который можно вставить на сайт, и FastAPI-эндпоинт POST /chat, который вызывает ShopAgent. Виджет должен нормально выглядеть на мобильном.

## 7. Перед сдачей
> Проверь проект: README (архитектура, запуск, данные) актуален, .env не в репозитории, все тесты проходят, нет мёртвого кода. Составь сценарий демо на 3 минуты по пунктам Must have.
